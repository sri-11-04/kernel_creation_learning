IRON RULES
01
Draw before you code
Every struct, every buffer — sketch memory layout on paper first. Kernels live and die on layout.
02
No dynamic allocation in exercises
malloc() is forbidden during this phase. Static buffers only. Feel the constraint the kernel lives under.
03
No global hidden state
Every function receives what it needs. Kernels hate hidden globals — they break re-entrancy.
04
Compile with -O2 from day one
Don't hide in debug mode. See what the compiler actually generates. Your mental model must match reality.
